- **Projet** : SIRH Intelligent (Laravel 11 + IA)
- **Stack** : Laravel 11, Livewire / Inertia.js + Vue 3 ou React, API OpenAI / Google Document AI, Docker, S3
- **Budget estimé** : 150 000 – 230 000 €
- **Planning** : ~6 mois
